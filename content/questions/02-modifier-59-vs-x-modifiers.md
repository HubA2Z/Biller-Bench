# Question
Our coder always uses modifier 59 when two procedures bundle. A payer told us to use X modifiers instead. What's the difference and when do we use each?

# Answer
**Short answer:** the X modifiers are more specific versions of 59. CMS says to use **XE, XS, XP or XU when one fits**, and 59 only when none of them describes the situation.

## What each one means
- **XE**: separate encounter (a different session on the same date).
- **XS**: separate structure (a different organ or anatomic site).
- **XP**: separate practitioner (performed by a different provider).
- **XU**: unusual non-overlapping service (doesn't overlap the main service's usual parts).

## Before using any of them
1. Look up the code pair in the NCCI procedure-to-procedure edits.
2. If the **modifier indicator is 0**, no modifier can bypass the edit.
3. If it's **1**, a modifier is allowed only if the documentation clearly shows the services were distinct.

## Commercial payers
Most follow NCCI logic, but modifier preferences vary. Some accept only 59, some require X modifiers. Check each payer's modifier policy.
