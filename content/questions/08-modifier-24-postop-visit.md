# Question
Our surgeon did a knee replacement last month. The patient came in this week for a shoulder problem. The visit was denied as part of the global surgery. Can we get it paid?

# Answer
**Short answer:** yes, if the visit was **unrelated to the surgery**. Add **modifier 24** to the E/M and link a diagnosis for the unrelated problem.

## What's included in a global surgical package
- Routine post-op visits related to the surgery.
- Treating usual post-op complications that don't need a return to the operating room (Medicare's rule).

## What can be billed separately
- Visits for **unrelated problems**: modifier **24**.
- The **decision for a major surgery** (90-day global) the day before or the day of surgery: modifier **57**.

## How to fix it
1. Make sure the note clearly addresses the unrelated problem.
2. Add modifier 24 and the unrelated diagnosis, and send a corrected claim (or request a Medicare reopening).
