## What it means

X12 describes code 136 as **failure to follow prior payer's coverage rules**, used only with group code **OA**.

## Common causes

1. **The primary denied for missing authorization or referral.**
2. **Out-of-network care** under the primary plan's rules.
3. **The primary's timely filing** wasn't met.

## How to fix it

1. **Look at the primary denial** and fix it if possible (authorization, appeal or corrected claim).
2. **Once the primary pays,** resubmit the secondary with the new primary remittance.
3. **If the primary denial stands,** check whether the secondary's policy allows any payment; usually it doesn't.

## Prevent it next time

- Follow the primary plan's authorization and network rules even when a secondary exists.
