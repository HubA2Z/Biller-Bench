## What it means

X12 describes code 226 as **information requested from the billing/rendering provider was not provided or not provided timely or was insufficient/incomplete**. A remark code says what was needed.

## Common causes

1. **A records request** that wasn't noticed or answered.
2. **Records sent to the wrong address** or without the request letter.
3. **Incomplete records** (for example, missing signed orders).

## How to fix it

1. **Find the request** (letter, portal message or remark code).
2. **Send complete documentation** with the request letter or reference number.
3. **Ask the payer how to get the claim reprocessed;** some reopen automatically, others need an appeal.

## Prevent it next time

- Route payer records requests to one person and track due dates.
