## What it means

The payer found **another claim with the same patient, provider, date of service, code and charge** and treated this one as a repeat. X12 says code 18 is used with group code **OA** (other adjustment), except where a state workers' compensation rule requires CO. The original claim may be paid, pending or denied for another reason.

## Common causes

1. **Resubmitting while the first claim is still in process.** The claim wasn't lost; it just hadn't finished processing.
2. **Sending a correction as a new claim.** Many payers need a corrected-claim indicator; without it the claim looks like a duplicate.
3. **Two identical services on the same day** without a modifier or units showing they were separate (for example, a repeat test).
4. **The same claim sent twice** through a clearinghouse and a payer portal.

## How to fix it

1. **Check the original claim's status** on the payer portal or your remittances. If it's paid, the duplicate denial needs no action.
2. **If the original is still pending,** wait for it to finish. Resending only creates more duplicates.
3. **If you meant to correct the claim,** use the payer's corrected-claim process. For commercial payers that's usually a replacement claim (frequency code 7) with the original claim number. For Medicare, use your MAC's reopening process for a processed claim.
4. **If the services were truly repeated,** correct the claim with the payer's repeat-service modifier (for example 76 or 77 for repeat procedures, or 91 for repeat lab tests) and documentation that supports it.
5. **If the original was denied for another reason,** fix that denial instead of resubmitting.

## Medicare vs. commercial payers

| | Medicare | Most commercial payers |
|---|---|---|
| Correcting a processed claim | Reopening through your MAC | Replacement claim (frequency code 7) with the original claim number |
| Repeat services | Modifiers 76, 77 or 91 as appropriate, with documentation | Same modifiers; check payer policy |

## Prevent it next time

- Check claim status before resubmitting anything older than about 30 days.
- Train staff on your payers' corrected-claim process and frequency codes.
- Send each claim through one channel only.
- Add repeat-service modifiers at charge entry when a test or procedure is repeated the same day.
