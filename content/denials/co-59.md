## What it means

X12 describes code 59 as **processed based on multiple or concurrent procedure rules**. When several procedures are done in the same session, payers usually pay the primary procedure at 100% and reduce the others.

This is different from **modifier 59**. The reason code is about **payment reductions**, not about distinct procedures.

## Common causes

1. **Multiple surgeries** in one session. Medicare generally pays the highest-valued procedure at 100% and other eligible procedures at 50%.
2. **Multiple imaging procedures** with reductions to the technical or professional parts.
3. **Concurrent care** by more than one provider on the same day.

## How to fix it

1. **Check which code was paid in full.** It should be the one with the highest allowed amount.
2. **Order lines by value** on the claim; some payers apply reductions based on line order.
3. **Check for exempt codes** (for example, add-on codes are usually not subject to multiple-procedure reduction); if one was reduced, ask for reprocessing.
4. **Otherwise, post the reduction** as a contractual adjustment.

## Prevent it next time

- List the highest-value procedure first.
- Know each payer's multiple-procedure policy.
