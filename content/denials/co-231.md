## What it means

X12 describes code 231 as **mutually exclusive procedures cannot be done in the same day/setting**. Payer edits (including NCCI) list code pairs that normally can't both be performed in one session.

## Common causes

1. **Two codes describing alternative approaches** to the same procedure.
2. **An initial and a repeat version** of a service billed together.
3. **Truly separate services** (different sites or sessions) billed without a modifier.

## How to fix it

1. **Check the code pair edit** and its modifier indicator.
2. **If only one procedure was done,** bill the code that best describes it.
3. **If both were done separately and a modifier is allowed,** add XE, XS, XP or XU (or 59 if none fits) with documentation, and send a corrected claim.
4. **Otherwise, adjust it off.**

## Prevent it next time

- Run NCCI edits before submission.
- Document separate sites or sessions clearly.
