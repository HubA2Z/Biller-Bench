## What it means

X12 describes code 236 as **this procedure or procedure/modifier combination is not compatible with another procedure or procedure/modifier combination provided on the same day according to NCCI or workers' compensation state regulations/fee schedule requirements**.

## Common causes

1. **An NCCI procedure-to-procedure edit** with no modifier, or with a modifier the documentation doesn't support.
2. **Incompatible modifiers,** such as conflicting side modifiers.
3. **State workers' compensation fee schedule rules.**

## How to fix it

1. **Look up the code pair** in the NCCI edits and check the modifier indicator (0 = no bypass, 1 = modifier allowed).
2. **If a modifier is allowed and justified,** add XE, XS, XP or XU (or 59 when none fits) and send a corrected claim.
3. **If not,** remove the bundled service or adjust it off.
4. **For workers' compensation,** check the state fee schedule rules.

## Prevent it next time

- Run NCCI checks before submission.
- Train coders on X modifiers versus 59.
