## What it means

X12 describes code 170 as **payment is denied when performed/billed by this type of provider**.

## Common causes

1. **A provider type the plan doesn't credential** for that service (for example, some plans limit which behavioral health or therapy provider types can bill).
2. **Billing under the wrong provider** when the service should be billed under a supervising physician (incident-to rules vary by payer).
3. **Wrong provider type** on the payer's enrollment record.

## How to fix it

1. **Check the payer's policy** on which provider types can bill the service.
2. **Check enrollment data** for the rendering provider.
3. **If another provider should have billed** under the payer's rules, correct the claim, but only where the documentation and supervision rules support it.
4. **Otherwise,** the denial stands.

## Prevent it next time

- Know each payer's credentialing rules for every provider type you employ.
