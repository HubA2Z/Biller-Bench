## What it means

X12 describes code 112 as **service not furnished directly to the patient and/or not documented**.

## Common causes

1. **Missing or unsigned documentation** for the date of service.
2. **Services not performed face to face** when the code requires it.
3. **Supervision rules** not met for services billed under a physician.

## How to fix it

1. **Pull the signed note** for the date of service.
2. **If documentation exists,** appeal with it.
3. **If the service wasn't furnished as the code requires,** correct the code or adjust it off.

## Prevent it next time

- Don't bill until notes are signed.
- Know each payer's rules for supervision and remote services.
