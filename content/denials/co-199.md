## What it means

X12 describes code 199 as **revenue code and procedure code do not match**. It applies to institutional (UB-04 / 837I) claims, where each line has a revenue code and often a HCPCS code.

## Common causes

1. **Charge master error,** with a procedure mapped to the wrong revenue code.
2. **Drugs or supplies** billed under a revenue code the payer doesn't accept for that HCPCS code.
3. **Payer-specific pairing rules** that differ from your defaults.

## How to fix it

1. **Look up the payer's revenue code requirements** for the HCPCS code.
2. **Correct the line** and resubmit (corrected institutional claim, type of bill ending in 7, where the payer accepts it).
3. **Fix the charge master** so it doesn't repeat.

## Prevent it next time

- Review revenue code and HCPCS mapping in your charge master at least yearly.
- Add pairing edits to your claim scrubber.
