## What it means

X12 describes code 146 as **diagnosis was invalid for the date(s) of service reported**. The code wasn't active on that date, or it isn't billable at that level of detail.

## Common causes

1. **Annual ICD-10-CM update:** a code was expanded into more specific codes, so the old code is no longer billable.
2. **A new code used before its effective date.**
3. **A category or header code** used instead of a complete, billable code.
4. **Outdated code lists** in the EHR or superbill.

## How to fix it

1. **Look up the code** in the ICD-10-CM version for the date of service.
2. **Pick the valid, most specific code** the documentation supports.
3. **Correct the claim and resubmit.**

## Prevent it next time

- Update your EHR and superbill code lists before each October 1.
- Review claims for service dates near the change dates.
